# Настройки

`/settings` — как приложение работает для этого человека. Данные аккаунта
(почта, пароль, сеансы) — в профиле, см. [вход и безопасность](account-security.md).

| Раздел | Где хранится | Код |
| --- | --- | --- |
| Внешний вид (тема) | `localStorage`, только это устройство | `preferences/PreferencesProvider.tsx` |
| Язык интерфейса | `localStorage`, только это устройство | то же |
| Уведомления | аккаунт на сервере, все устройства | `components/settings/NotificationsSection.tsx` |

## Уведомления

Один переключатель — «Перевод готов»: письмо, когда перевод книги закончился
или не удался (`document_ready` в `GET`/`PUT /api/account/notifications`).

- Переключатель меняется сразу, запрос идёт следом
  (`account/notificationQueries.ts`, `useMutation` с `onMutate`). При ошибке
  возвращается прежнее положение и предлагается повторить. Быстрые нажатия
  подряд уходят по очереди (`scope`), поэтому сохраняется последнее.
- Ответ `PUT` записывается в кэш как сохранённое значение.
- Под переключателем — когда письма не будет. Так решает бэк
  (`DocumentNotificationStore.skipReason`):
  - перевод занял меньше минуты (человек, скорее всего, ещё на странице);
  - почта не подтверждена — для этого случая отдельное предупреждение.

Проверено вживую: выключение → `PUT {"document_ready":false}` → после
перезагрузки выключено; включение возвращает исходное значение. Тесты —
`src/test/notificationSettings.test.tsx`:
- сохранение;
- откат при ошибке и повтор;
- неподтверждённая почта;
- ошибка загрузки.
